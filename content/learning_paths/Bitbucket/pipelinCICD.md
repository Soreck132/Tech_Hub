## 0.1 WHAT IS CI/CD

    CI/CD Definición:

    CI: Integración continua, donde los desarrolladores integran código frecuentemente en un repositorio compartido.
    CD: Entrega continua, automatiza la construcción y pruebas para tener software listo para producción.
    CD (Despliegue continuo): Automatiza el despliegue en producción sin intervención humana.

    Fases de CI/CD:

    Integración: Combinar código y ejecutar pruebas unitarias para detectar errores temprano.
    Entrega: Ejecutar pruebas más rigurosas y preparar el software para su lanzamiento.
    Despliegue: Publicar automáticamente el software en producción si pasa las validaciones.

    Objetivos:

    Detectar y resolver problemas rápidamente.
    Mantener siempre una versión lista para producción.
    Liberar software de forma rápida y confiable.

    Bitbucket Pipelines:

    Automatiza cada fase del proceso CI/CD.
    Facilita la creación de workflows para pruebas, construcción y despliegue.
